# 元气小练

元气小练是一款面向健身新手的个人训练记录工具。它把当天训练整理为清晰的顺序：确认身体状态、热身、正式训练、按需专项和拉伸收尾。

## 使用方式

1. 在“今日”确认当天的精神、睡眠和酸痛状态。
2. 点击“开始今日训练”，依次完成热身与正式训练动作。
3. 根据建议选择专项训练，并在结束后完成拉伸放松。
4. 在“概述”查看训练完成情况、近期趋势和俯卧撑目标进度。

## 你可以做什么

- 记录每天的训练完成项、身体状态和可选饮食信息。
- 切换训练阶段，或在“我的”中创建自己的阶段。
- 查看每个动作的示范图、组数次数和动作提示。
- 上传头像，并编辑个人训练资料。
- 导出与导入本地备份，换设备时恢复自己的记录。

## 数据与隐私

元气小练不需要注册账号。训练记录和个人资料默认保存在当前设备的浏览器本地；不同设备之间不会自动同步。建议定期在“我的”中导出备份。

## 使用提醒

本工具提供一般性训练组织与记录，不替代医疗或专业康复建议。出现持续疼痛、眩晕或明显不适时，请停止训练并咨询医生或专业人士。
